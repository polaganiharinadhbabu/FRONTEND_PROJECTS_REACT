# Frontend Projects (React.js)

A collection of React frontend projects and mini-applications showcasing various UI components, state management patterns, and interactive user experiences.

## 🚀 Projects Included

1. **404-page-react** - Custom 404 Not Found error page
2. **bookmark-saver-react** - URL bookmark manager application
3. **color-palette-react** - Interactive color palette generator & previewer
4. **coming-soon-react** - Coming soon landing page with countdown timer
5. **contact-form-react** - Interactive contact form with input validation
6. **contact-page-react** - Complete responsive contact page layout
7. **currency-converter-react** - Real-time currency exchange rates & converter
8. **drag-and-drop-react** - Drag and drop list/task management interface
9. **expense-tracker-react** - Personal budget and expense tracker
10. **form-validator-react** - Comprehensive form input validation
11. **github-finder-react** - GitHub user profile and repository search tool
12. **login-app** - Modern authentication & login UI
13. **newsletter-signup-react** - Newsletter subscription card with feedback states
14. **password-generator-react** - Customizable random password generator
15. **pricing-cards-react** - Responsive subscription pricing tier cards
16. **quiz-game-react** - Interactive trivia/quiz game with scoring
17. **react_starter** - Minimal React starter template
18. **recipe-finder-react** - Recipe search application with ingredient filters
19. **scroll-progress-react** - Custom scroll reading progress indicator
20. **team-showcase-react** - Team members showcase grid/cards
21. **todo-app-react** - Task and todo management application

## 🛠️ Getting Started

To run any of the projects locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/polaganiharinadhbabu/FRONTEND_PROJECTS_REACT.git
   ```

2. Navigate into the specific project directory:
   ```bash
   cd FRONTEND_PROJECTS_REACT/<project-name>
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
